What is this?

This is the Java Lab 5 rebuilt to run entirely in your browser. Each airline server keeps a table of listeners. A client joins over TCP port 8189 by sending ADD <ip> <port>; the server answers HELLO. Every few seconds the server sends each listener a UDP datagram such as CarmonCar,Newark,SEAT,3,GATE,17.

Browsers cannot open real sockets, so the network is simulated. The rules are the same: TCP retransmits lost segments and either succeeds or times out; UDP datagrams are sent once and simply vanish when lost. Open this page in a second tab to add a second machine to the network.
